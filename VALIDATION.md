**Behavior and visual checks**

The complete suite passes **204 tests**. Coverage includes existing SSE/raw/JSON/transform/log/reconnect behavior, explicit raw omission, numeric uptime, restart inference, shared series, numerical compaction, CSV snapshot consistency, raw/series downloads, the single export path (every export button downloads one ZIP with export.txt and valid CRCs, including single-file and graph-free exports, and reports failures next to Export All), extreme finite values, lifecycle cleanup, touch/keyboard inspection, synchronized plots, and resizing selected off-screen panels without horizontal overflow. Plot interaction tests cover click-to-activate, the Live state and one-time Fit, the zoom and measurement bands, A/B marker labels, markers stopping Live, measuring without moving the page layout, toolbar focus, shortcuts after clicks outside the canvas, selectable readout/legend/measurement text, the reserved control band, the cut-off key legend that fades and shows in full on hover, generated headers, the enlarged view with its history entry and shortcuts, the leave warning and what counts as saved, and discrete lanes: change-only storage, bus and logic values, hashed colors with a hue-aware second choice, snapping, lane measurements, lane exports and the lane-only graph.

History tests compare counts, means, population variance/deviation, extrema and their timestamps against independent reference calculations. They cover gaps, duplicate times, small budgets, many restarts, stable snapshots, and values near 1e308 and 1e-300. Busy channels can use otherwise idle channels' capacity without premature compaction.

The actual example was inspected at 1400-, 1100- and 390-pixel widths, both live and with A/B measurement. A test checks that it needs no classes or page stylesheet, shows two columns at 2400 and 1100 pixels, stacks at 390 pixels, never scrolls horizontally, caps the page at 1920 pixels with the topbar content aligned to it, and keeps the y-axis gutter narrow. Screenshots are generated under the ignored `test-results/` directory. The example includes overlaid temperatures, synchronized speed/voltage panels, numeric unit conversion, toolbar uptime, separate CSV files and simulated restarts.

The build is deterministic and `tools/build.py --check` passes. C99 and C++11 tests verify both uncompressed and compressed firmware headers against the generated bytes, including decompression. The build remains Python-only with rjsmin; no plotting/runtime dependency was added.

**Accelerated eight-hour data set — final source**

[Report](benchmarks/graph-history-8h.json): eight channels × 100 Hz × eight simulated hours = **23,040,000 values**. This is a fast data-generation test, not an eight-hour wait.

Ingestion and reference calculation took **1.68 seconds**. Peak accounted history was **33,554,432 bytes**, within 32 MiB. All counts, extrema, means and variances matched the reference; no history was expired. Full-range and narrow indexed queries had a combined eight-channel p95 of **0.100 ms** on this machine.

**Live runs and their scope**

- [Final JavaScript release check](benchmarks/graph-release-15s.json): real SSE, four panels/eight channels, 100 groups/second for 15 seconds, with two complete snapshot exports, each downloaded as one ZIP holding export.txt and nine CSV files. All 1,515 messages arrived; every series retained 1,500 valid measurements; no errors. It was rerun after the restyling and the enlarged view, and this report's JavaScript hash matches the shipped build.
- That release check averaged **28.9 canvas draws per configured panel per second**. Cursor-handler p95 was **0.300 ms**; event-to-next-animation-frame p95 was **17.00 ms**. Render-callback p95 was **3.10 ms**.
- [High-rate check](benchmarks/graph-final-20s.json): the preceding layout build received all 20,020 messages / 160,000 measurement values in 20 seconds at 1,000 groups/second. A 1 MiB graph budget forced compaction, with two nine-file export preparations and no errors. The later change formatted large/small display numbers in scientific notation.
- [Completed ten-minute soak](benchmarks/graph-soak-10m.json): an earlier hardened build received all 75,600 messages / 600,000 measurement values at 125 groups/second, under an 8 MiB graph budget, with four nine-file export preparations and no errors. Its tested hash is recorded; it predates shared idle-capacity borrowing and the last layout refinements.
- [Thirty-minute live observations](benchmarks/graph-live-30m-observations.json): the first 30 minutes of the earlier long run, recorded before later numerical/layout refinements. The user requested a 30-minute limit, so the longer process was interrupted and no final end-of-run assertion/timing summary is claimed for it. This file is explicitly observation-only evidence, not a final-build pass.

Callback timings exclude browser paint and include lightweight animation callbacks as well as draws. Cursor next-frame timing is not a complete input-to-photon measurement. Heap figures force GC and exclude some browser-native memory; history accounting covers typed storage plus node allowances, not exact total heap usage. Performance is specific to the recorded browser/hardware and workload. Historical raw/scalar reports under `benchmarks/` predate this graphing feature and are not final-build performance claims.
